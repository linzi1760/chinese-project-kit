# AI 自动接续：最小可验证工作流（v0.2 候选）

## 目标与边界

用户正常提出「继续开发」「修复问题」「整理成果」等项目任务时，**支持加载 Skills 的助手**可以主动检查项目并复用既有进度。独立 CLI 不具有语言理解和后台调度能力；本实现**没有验证** ChatGPT 网页版的自动调用、跨机器同步、全天候后台执行，也不是已发布的 ChatGPT 插件。不要据此宣称“安装后从此不用管”。

保留原 `project_kit.py init/check` 和八目录合同；新增 `scripts/project_kit_agent.py`，只用标准库。

## AI 何时使用

- 有明确代码库或已授权的工作区，并且用户要求建立、继续、排查、实现、检查或交付**持续性的项目工作**时，可在后台先执行 `inspect` / `status`，无需用户每次说 Skill 名字。
- 若发现标准项目包：**复用原 `01_需求与设计/工作计划.json`**。不得新建第二套计划。
- 若为其他已存在的项目：可只读 `inspect`；当用户已授权在该项目上持续管理进度时执行 `adopt`，仅在**仓库外**存放项目路径、任务标题和状态。不移动、不重命名、不复制原始资料。
- 仅问概念、翻译一句话、单文件临时处理时，不自动建立项目台账。
- 用户的授权限于当前工作区内必要操作；删除原文件、外发材料、对外发布、推送代码、合并、付费和部署仍须相应授权。

## 不需要用户重复讲述项目进度的使用流程

以下命令在仓库根目录执行；如果不在仓库内，提供 `--root`。已有仓库只需第一次 `adopt`，重复调用会返回 `created=false` 并复用原计划。

```bash
# 只读取目录信息；不能据此声称理解业务功能
python scripts/project_kit_agent.py inspect --root "项目绝对路径"

# 仅已授权的现有项目需要执行，标准项目包不重复建计划
python scripts/project_kit_agent.py adopt --root "项目绝对路径"

# 新对话 / 新 Agent 先读取真正的持续状态
python scripts/project_kit_agent.py status --root "项目绝对路径"

# 假设 status 返回 revision 0：新增计划任务
python scripts/project_kit_agent.py task-add --root "项目绝对路径" --expected-revision 0 --id T-01 --title "修复已有问题"

# 假设上一步 revision 1：开始执行
python scripts/project_kit_agent.py task-set --root "项目绝对路径" --expected-revision 1 --id T-01 --status doing
```

任何写入返回的 `revision` 都可能立刻过期，**每次写入必须携带从 `status` 读到的 expected-revision**。如果提示冲突，重新读取状态后合并意图并重试，绝不能删除或直接覆盖新计划。任务状态必须依据实际执行更新，不得用主观判断直接设为 `done`。

## 完成声明与验收

此候选版本允许记录 `planned` → `doing` → `verifying` 等进度，并**拒绝所有直接写入 `done` 的请求**；它还不能自动核验专业测试，也不能自动完成任务。实际工作完成后，须记录真实测试/阅读/渲染证据，并使用适用的专业验收流程。原项目 `project_kit.py check --delivery` 依然只核对记录与文件存在，不代表内容质量或应用真实可用。后续需要独立的可信验收适配器。

## 状态保存、安全与恢复

- 标准项目包更新原计划文件，增加 `revision` 字段，与原检查器兼容。
- 其他已有仓库默认保存到用户目录的 `.chinese-project-kit/projects/<项目路径哈希>/`；可用 `--state` 指定**位于源码仓库外**的绝对目录。路径哈希只用于索引，不是加密存储。
- 索引只包含项目真实路径和明确登记的任务元信息，不复制用户源文件，但路径和任务标题本身仍可能敏感；不要把个人或客户资料提交到公开仓库。
- 写入采用锁文件、修订号比较和同目录原子替换；进程崩溃若留下 `.project-kit.lock`，工具会拒绝覆盖，需先核实无其他写入者再手动处理。不要擅自删除正在使用的锁。
- 不承诺不同电脑、ChatGPT 网页版和 Codex 同步。需要跨设备持久共享时须设计经授权的后端和权限边界。

## 可复现实验

```bash
python -m unittest discover -s scripts -p 'test_project_kit_agent.py' -v
```
